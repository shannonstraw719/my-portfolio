# Task Manager

A responsive task management web application built with HTML, CSS, and JavaScript.

## About the Project

I created this project as my first software development project while studying Software Engineering at Southern New Hampshire University.

The application allows users to create, manage, and organize tasks through a simple and responsive interface.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks by All, Active, or Completed
- Track remaining tasks
- Clear completed tasks
- Set due dates
- Identify overdue tasks
- Save tasks using browser localStorage
- Responsive design for smaller screens
- Add tasks using the Enter key

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## What I Learned

This project helped me practice working with the Document Object Model (DOM), event listeners, arrays, objects, functions, filtering, and browser storage.

I also learned how different parts of a web application work together to create an interactive user experience.
